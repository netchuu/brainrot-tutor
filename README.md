# Brainrot Tutor

Turns a PDF or notes into short TikTok-style lessons built from our own video templates, then quizzes you on them. SkillLab AI Hackathon project.

- `backend/`: FastAPI API (script, voice, pictures, quiz, tutor)
- `frontend/`: Vite + React player and screens
- `contracts/`: the API contract both sides build against, with fixtures and a validator
- `docs/PLAN.md`: scope, templates, asset names, milestones

Agent instructions: `CLAUDE.md` and each folder's `CLAUDE.md`.
